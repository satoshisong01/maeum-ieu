# 마음이음 — 치매 선별 테스트 플레이북 (팀 테스트용)

> 이 문서 하나로 바로 테스트할 수 있게 만들었습니다. **앞쪽 = 따라 하기, 뒤쪽(부록) = 용어 설명.**

---

## 1. 30초 시작 가이드

1. **계정 만들기** — `/signup`에서 새 계정 생성 (나이 70~85, 성별 자유). 한 명이 여러 개 만들어 테스트.
2. **대화 들어가기** — 로그인 → `/chat` → **"글씨로 대화하기"** 클릭.
3. **아래 문장을 그대로 입력** — 영역별 카드(3번)의 문장을 따라 입력.
4. **결과 확인** — `/dashboard`(건강 기록)에서 **영역별 점수·일별 추세·종합 등급**을 확인.

> 💡 **핵심 팁**
> - **중증(이상) 테스트**는 쉬워요. AI가 안 물어봐도 **그냥 그 문장만 입력하면** 바로 잡힙니다.
> - **정상·경증 테스트**는 **AI가 그 영역을 물어볼 때 답해야** 점수가 잡혀요. (AI가 "오늘 무슨 요일이에요?"라고 물으면 → 그때 답하기)
> - 점수는 화면에 안 보입니다(어르신 보호). **대시보드/개발자 로그**로만 확인.

---

## 2. 결과는 4단계로 나뉩니다 (한눈에)

| 등급 | 언제 | 보호자 안내 |
|------|------|-------------|
| 🟢 **정상** | 기간 평균 점수 < 0.3 | "정상 범위입니다" |
| 🟡 **경증** | 0.3 ~ 0.8 | "경미한 변화, 지속 모니터링 권장" |
| 🟠 **중증(의심)** | 0.8 ~ 1.5 | "인지 저하 가능성, 전문의 상담 권장" |
| 🔴 **고위험** | ≥ 1.5 | "심각한 인지 저하 의심, 즉시 상담" |

- 각 **발화(질문 답변)** 는 영역별로 **0(정상) / 1(경계) / 2(주의)** 점수가 매겨집니다.
- 위 4단계는 **여러 발화의 평균**으로 정해집니다. → 중증 발화를 여러 번/여러 영역 쌓으면 등급이 올라갑니다.

## 3. 영역별 테스트 카드 (그대로 따라 하기)

> 표기: 📍**중증(2) 입력** = 그냥 입력하면 잡힘 / 🟢**정상(0)** · 🟡**경증(1)** = AI가 물어볼 때 그렇게 답하기

### ① 시간 지남력 (오늘 날짜·요일·계절)
- 📍 **중증(2)**: `오늘이 2003년 3월쯤이지? 곧 봄이라 좋구만`  → 기대: 시간 지남력 **주의(2)**
- 🟢 **정상(0)**: AI가 "오늘 무슨 요일이에요?" 물으면 → `금요일이지` (실제 요일 맞게) → **정상(0)**

### ② 장소 지남력 (지금 어디 있는지)
- 📍 **중증(2)**: `나 지금 뉴욕 한복판에 나와 있어 사람이 엄청 많네`  → 장소 지남력 **주의(2)**
- 🟢 **정상(0)**: AI가 "지금 어디 계세요?" 물으면 → `집이지 뭐, 우리 동네` → **정상(0)**

### ③ 즉시 기억 (방금 들은 단어)
- 🟢 **정상(0)**: AI가 "단어 세 개 외워보세요~ 나무, 자동차, 모자" 하면 → 바로 `나무, 자동차, 모자` 따라 말하기 → **정상(0)**
- (즉시 기억은 보수적이라 '중증'을 일부러 만들기 어렵습니다 — 정상 확인 위주)

### ④ 지연 기억 (조금 뒤에 회상) — 정상/경증/중증 모두 만들기 좋음
> **2단계**: 먼저 AI가 단어 3개를 외워주게 한 뒤(예: "민지야 우리 단어 외우기 하자"), 몇 마디 지나고 AI가 "아까 그 단어 기억나세요?" 물을 때:
- 🟢 **정상(0)**: `나무, 자동차, 모자!` (3개 다)  → **정상(0)**
- 🟡 **경증(1)**: `나무랑… 자동차… 나머지는 모르겠네` (2개만)  → **경계(1)**
- 📍 **중증(2)**: `글쎄… 하나도 기억이 안 나` (0~1개)  → **주의(2)**

### ⑤ 언어 능력 (단어 찾기·유창성·속담)
- 🟢 **정상(0)**: AI가 "1분 안에 동물 이름 많이 대보세요" 하면 → `사자, 호랑이, 코끼리, 기린, 원숭이, 토끼, 강아지, 고양이, 사슴, 곰`(9개+) → **정상(0)**
- 🟡 **경증(1)**: AI가 "'백문이 불여일견' 무슨 뜻?" 물으면 → `백 번 들으라는 말 아닌가?`(글자 그대로) → **경계(1)**
- 📍 **중증(2)**: AI가 동물 이름 물을 때 → `동물… 그거… 그거 뭐더라… 잘 생각이 안 나네`(3개 미만/단어찾기 실패) → **주의(2)**

### ⑥ 판단력 (상황 대처·사회적 판단)
- 📍 **중증(2)**: `어제 이순신 장군이 우리집에 차 마시러 왔다 갔어` (사망 인물 접촉)  → 판단력 **주의(2)**
  - 다른 예: `다음 달에 군대 입대해서 걱정이야`(연령 안 맞는 계획) · `새마을운동 하러 가야지`
- 🟢 **정상(0)**: AI가 "길에서 지갑을 주우면?" 물으면 → `주인 찾아주거나 경찰서에 갖다줘야지` → **정상(0)**

### ⑦ 주의력·계산 (숫자·거스름돈)
- 📍 **중증(2)**: `어제 만원짜리 책 샀는데 거스름돈을 2만원이나 받아왔어` (불가능한 거래)  → 계산 **주의(2)**
- 🟢 **정상(0)**: AI가 "100에서 7을 빼면?" 물으면 → `93` → **정상(0)**
- 📍 **중증(2)**: AI가 "100에서 7을 빼면?" 물을 때 → `85`(틀린 답) → **주의(2)**

## 5. 종합 등급 올려보기 (중증→고위험 만들기)

한 계정에서 **여러 영역의 중증(2) 문장을 같은 날 여러 번** 입력하세요. 예:
1. `오늘이 2003년 3월이지?` (시간 2)
2. `나 지금 뉴욕에 나와 있어` (장소 2)
3. `어제 이순신 장군이 왔다 갔어` (판단 2)
4. `만원짜리 책 샀는데 거스름 2만원 받았어` (계산 2)

→ `/dashboard` 종합 요약문이 **"정상 → 경미 → 인지 저하 가능성 → 심각"** 으로 올라가는지 확인.
(반대로, 일상 대화만 하면 계속 🟢 정상이어야 정상입니다.)

# 부록 A. 용어 설명

- **인지 영역(7개)**: 시간 지남력 / 장소 지남력 / 즉시 기억 / 지연 기억 / 언어 / 판단력 / 주의·계산.
- **점수(영역별)**: **0 정상 / 1 경계 / 2 주의** — 발화 하나하나에 매겨짐.
- **등급(종합)**: 기간 평균으로 **정상 / 경증 / 중증(의심) / 고위험** 4단계.
- **이상 징후(isAnomaly)**: 한 발화에서 점수 2가 하나라도 나오면 그 발화는 '이상'으로 기록.
- **응급 단계(L1/L2/L3)**: 신체·자해 위급 신호(인지 점수와 별개). L3 = 즉시 119/109.
- **정탐/오탐/미탐**: 정탐=유도대로 잡힘 · 오탐=정상인데 이상으로 잡힘 · 미탐=이상인데 못 잡음.

# 부록 B. 기반 한국형 인지 검사 도구 (참고)

우리 질문들은 아래 표준 검사 도구의 문항을 **대화로 바꾼 것**입니다.

- **MMSE-K (간이정신상태검사)**: 가장 보편적인 치매 선별. 30점. → 단어 3개·100-7·요일/날짜·따라말하기.
- **MoCA-K (몬트리올 인지평가)**: 초기·경도 인지장애에 더 민감. 30점. → 5단어 회상·동물 이름대기·공통점.
- **KDSQ-C (한국형 치매선별 설문-인지)**: 일상 관찰 15문항(6점↑ 의심). → 반복·이름 못 떠올림 등 자동 관찰.
- **AD8**: 보호자 관찰 8문항(2점↑ 의심). → 흥미감소·약속 못 지킴.
- **CDR (임상치매척도)**: 중증도 0·0.5·1·2·3 단계. → 우리 4등급의 임상 기준점.
- **GDS-K (노인우울척도)**: 우울 동반 평가(5점↑ 의심). → 기분·수면·흥미 질문.

# 부록 C. 점수 → 등급 매핑 (개발자 확인용)

- 영역별 점수는 `cognitive_assessments` 테이블에 저장(domain, score 0/1/2).
- 종합 등급은 `/api/summary`의 기간 평균(overallAvg)으로 산출: `<0.3 정상 / 0.3~0.8 경증 / 0.8~1.5 중증 / ≥1.5 고위험`.
- 서버 로그 `[cognitive-analysis] {isAnomaly, checks}` 로 실시간 확인 가능.

> 상세한 판단 기준·코드 근거는 별도 문서 **`치매선별_판단기준_및_검증가이드`** 참고.
