## 4. 비용 방어 현황과 남은 레버

지금 작동 중인 방어:
- 모델 하이브리드(분석기 승급분만 3.5) + 2단 라우팅(lite 83~89%)
- thinkingBudget 전 경로 제한(동반자 256·분석기 1024·STT 64·요약 512·검진채점 64·추출 128)
- implicit caching(분석기 70%·승급 80% 적중) — 프롬프트 정적 우선 배치 효과
- 일반인 모드: 분석기 미실행 + 질문풀 미주입 + 검진 LLM 우회

남은 레버 (착수 전):
1. **explicit caching** (@google/genai 마이그레이션 완료로 준비됨): companion 적중률 24%→~100% 확정화 시 입력비 추가 ~20% 절감. 손익분기 시간당 5~9턴 — 출시 후 켜기
2. 음성 비중 증가 시 Cloud TTS 단가 협상/캐싱(같은 문장 재합성 방지)
3. Batch API(요약 롤업 50% 할인) — 현재 비중 작아 보류
