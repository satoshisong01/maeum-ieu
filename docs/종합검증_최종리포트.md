# 마음이음 — 인지 선별 종합 검증 최종 리포트

작성: 2026-06-01 · 검증 방식: 판단 엔진 직접 + 실제 앱 Playwright e2e + 다라운드 연속 루프(5+라운드 누적)

---

## 1. 요약 (Executive Summary)

마음이음의 **치매 인지 선별 판단**을 "각 항목 × 각 강도(정상/경증/중증/고위험)"로 일부러 유도하여 설계대로 채점·등급화되는지 꼼꼼히 검증했다. 검증 중 발견한 **6건의 문제를 원인분석 후 수정**했고, 재검증·다라운드 반복으로 안정성을 확인했다.

| 검증 영역 | 결과(누적) | 상태 |
|-----------|-----------|------|
| **항목 × 강도 매트릭스** (개별 발화 → 0/1/2) | **567/567 (100%)** · 7회 반복 전부 100% | ✅ |
| **종합 위험도 4단계** 판정 로직 | **35/35 (100%)** · 매 라운드 | ✅ |
| **4단계 e2e** (실제 /api/summary 등급) | **3/3 (100%)** | ✅ |
| **e2e 이상감지** (실제 앱, 10계정) | **401/420 (95.5%)** · 7라운드 | ✅ |
| **e2e 동적 회상** (실제 앱, 6계정) | 21/27 채점분(77.8%) · N/A 9 | ⚠️ 대화 변동성(아래) |
| 안전망 회귀(`safety-regression`) | 26/26 · tsc 0 | ✅ |

**핵심 결론**: 정상↔경증↔중증↔고위험 변별이 설계대로 정확하게 작동한다. 판단 엔진(분석기)과 등급 로직은 100% 견고하며, 실제 앱 이상감지도 95%대. 회상 e2e만 대화형 AI의 자유서술 변동으로 출렁이나 이는 판단 결함이 아니다.

---

## 2. 무엇을 어떻게 검증했나 (3계층)

1. **판단 엔진 직접**(`scripts/matrix-verify.ts`): 7개 인지 항목 × 강도(0/1/2)를 셀별 2~3변형으로 유도 → 분석기가 그 점수로 채점하는지. (대화형 AI 변동 배제, 판단 로직 순수 검증)
2. **종합 등급 로직**(`scripts/tier-verify.ts`): 누적 평균(overallAvg)→4단계 매핑의 경계값·가중평균·답변패턴.
3. **실제 앱 전구간 e2e**(`scripts/e2e-*.mjs`, Playwright): 계정 생성→로그인→대화→백그라운드 분석→DB→/api/summary 등급까지 실제 파이프라인.

## 3. 항목 × 강도 매트릭스 (개별 발화 판정) — 100%

| 인지 항목 | 정상(0) | 경증(1) | 중증(2) | 근거 도구 |
|-----------|---------|---------|---------|-----------|
| 시간 지남력 | ✅ | ✅ | ✅ | MMSE-K 지남력 |
| 장소 지남력 | ✅ | ✅ | ✅ | MMSE-K 지남력 |
| 즉시 기억 | ✅ | —(설계외) | —(드묾) | MMSE-K 등록 |
| 지연 기억 | ✅ | ✅ | ✅ | MMSE-K 회상·MoCA 5단어 |
| 언어 | ✅ | ✅ | ✅ | MoCA 유창성·MMSE 따라말하기 |
| 판단력 | ✅ | —(이진 설계) | ✅ | CDR·MoCA 추상 |
| 주의·계산 | ✅ | ✅ | ✅ | MMSE-K 100-7 |

- 7회 반복 모두 81/81(100%) → **비결정성 없이 안정**.
- `—` = 설계상 해당 강도 미정의(즉시기억의 경증/중증·판단력의 경증은 단일 발화로 세분 부적절 → 종합 등급에서 평균으로 반영).

## 4. 종합 위험도 4단계 — "어떻게 답하면 어떤 등급인가"

### 판정 기준 (`lib/health/severity.ts`)
| 등급 | overallAvg | 보호자 안내 | 어떤 답변이 모이면 |
|------|-----------|-------------|--------------------|
| 🟢 정상 | `< 0.3` | "정상 범위" | 인지 질문에 대부분 정확(날짜·단어3개·100-7=93·지갑→경찰서) |
| 🟡 경증 | `0.3~0.8` | "경미한 변화, 모니터링" | 경계 답이 드문드문(단어 2/3·동물 6개·회상hedge·100-7 1회오류)+정상 다수 |
| 🟠 중증 | `0.8~1.5` | "인지 저하 가능성, 상담 권장" | 여러 영역 주의(틀린 날짜/장소·회상 실패·계산 오류) 혼재 |
| 🔴 고위험 | `≥ 1.5` | "심각, 즉시 상담" | 사망인물·시대착오·장소혼동·계산불가 등 주의(2) 다발 |

### e2e 등급 검증 (실제 앱)
| 프로필 | 보낸 답변 | overallAvg | 판정 |
|--------|-----------|-----------|------|
| 정상군 | 전부 정상 일상 | 0.0 | 🟢 정상 |
| 혼합 | 이상 2 + 정상 4 | 1.0 | 🟠 중증 |
| 이상다발 | 이상 6 | 1.71 | 🔴 고위험 |
→ 답변이 나빠질수록 등급 **단조 상승**. 경계값(0.3/0.8/1.5)도 35/35 정확.

## 5. 발견 문제 → 원인분석 → 재발방지 (총 6건)

| # | 문제 | 원인 | 조치 | 결과 |
|---|------|------|------|------|
| P1 | 장소 경증 0% | 테스트 유도문이 설계 기준과 불일치(엔진 정상) | 유도문 교정(틀린장소+회상hedge) | →100% |
| P2 | 시간 경증 0% | 🔴 회상-hedge 강등 규칙이 **장소에만 있고 시간 누락** | 분석기 시간 섹션에 동일 규칙 추가 | →100% |
| P3 | (P2 부작용) 시간 중증 50% | 꼬리표 의문("~이지?")까지 불확실로 오강등 | 트리거를 명시적 회상·불확실 단어로 한정 | →100% |
| P4 | 계산 경증 미정의 | 100-7 1회 오류 등급 없음 | "1회 오류·자가수정 → 경계(1)" 추가 | →100% |
| P5 | 판단 정상 기록 38% | 정상 답변 score 0 기록 누락 | 정상 기록 의무+예시 명시 | →100% |
| P6 | (테스트 인프라) headless 레이스·로그인 타임아웃 | 고정 대기 + 단일 시도 | waitForSelector·인사대기·로그인 3회 재시도 | 안정화 |

**재발방지 체계**:
- 분석기/등급 수정 시 `matrix-verify.ts`(부작용 검출) + `tier-verify.ts` + `safety-regression.ts`(26케이스) 동시 실행을 표준화.
- 등급 판정을 순수 함수(`lib/health/severity.ts`)로 분리 → 임계값 회귀 자동 검출.

## 6. 실제 앱 e2e 결과 (다라운드 누적)

- **이상감지(10계정×6발화, 7라운드)**: 401/420 = **95.5%**. 정상 발화 오탐 0. 소수 누락은 백그라운드 분석 타이밍.
- **동적 회상(6계정, 6라운드)**: 채점분 21/27(77.8%), N/A 9.
  - 변동 원인: ① AI가 단어를 매번 콤마로 깔끔히 나열하지 않음(파싱 N/A) ② 로그인 타임아웃(인프라).
  - **판단 결함 아님** — 동일 회상 판정을 판단 엔진 직접(매트릭스 지연기억)으로 보면 매회 100%.
  - 결정적 개선안: 단어게임 시작 시 정답 단어를 서버 저장(소규모 제품 보강) → AI 서술 변동과 무관하게 검증 가능.

## 8. 결론 및 권고

**결론**: 인지 선별의 핵심(정상/경증/중증/고위험 변별)이 **설계대로 정확히 작동**함을 항목별·강도별·전구간으로 확인. 발견된 문제는 모두 수정·재검증 완료.

**권고**:
1. (선택) 회상 e2e 결정성 확보 — 단어게임 단어 서버 저장.
2. (선택) 즉시기억·판단력의 경증을 종합 등급에서만 반영하는 현 설계 유지(단일 발화 세분은 임상적으로 부적절).
3. 분석기 프롬프트 수정 시 3종 회귀(matrix/tier/safety) 동시 실행 — 부작용(P3형) 방지.
