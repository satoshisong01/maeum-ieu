> 자세한 내용은 첨부된 사용 설명서(갱신본)를 참고해 주세요.

### 보호자별 리허설 (보호자 1명당 ~3분, 재개 D-1)
1. [ ] 보호자 폰에 마음이음 앱 설치·로그인 확인 (푸시는 앱 설치가 전제)
2. [ ] 운영자가 해당 어르신 계정으로 `/live` 접속 → [📞 대화 시작하기]
3. [ ] 위급 테스트 발화 1회: **"가슴이 너무 아프고 숨이 차"** (L3 즉시 알림 어휘)
4. [ ] 보호자 폰에 푸시 도착 확인 (수십 초 내) + 이메일 수신 확인
5. [ ] 보호자 앱의 [위급 이력]에서 해당 건 표시 확인
6. [ ] 확인 후 운영자: 해당 테스트 대화를 어르신 이력에서 정리(운영 데이터 오염 방지 — 담당자에게 "정리" 요청)
7. [ ] "그만"으로 세션 종료 확인
