# 적응형(양방향) 대화 검증 리포트

작성: 2026-06-01 · 방식: Playwright로 실제 앱에 접속, **AI 응답을 읽고 어르신 역할로 그에 맞춰 답하는 진짜 양방향 대화**(스크립트 고정 발화 X)

---

## 1. 무엇을 했나
지금까지는 "정해둔 문장을 던지는" 테스트였다면, 이번엔 **AI가 한 말을 읽고 → 어르신처럼 그에 맞춰 다음 말을 이어가는** 자연스러운 대화로 검증했다. (계정: 페르소나 할머니 / 동반자 "지윤")

## 2. 대화 흐름 (요약)
| 턴 | 어르신(테스터) | AI(지윤) 반응 | 관찰 |
|----|----------------|----------------|------|
| 1 | "오늘 날씨 좋아 기분 좋네" | 공감 + **"지금 계절이 어느 때쯤?"** | AI가 자연스럽게 시간 감각 질문 |
| 2 | "봄 끝나가고 곧 여름이지, 5월 말" | "맞아요!" + 다음 화제(여름 음식) | 정답 인정, **계절 재질문 안 함** |
| 3 | "여름엔 콩국수지" | 콩국수 설탕/소금 | 자연 대화 |
| 4 | "만원짜리 두부 샀는데 거스름 2만원 받았어" | **"만 원 내셨는데 이만 원 돌려받으신 거예요?"** | **불가능한 거래를 부드럽게 포착(좌절 없이)** |
| 5 | "응 만원 내고 이만원 받았어" | (확인) | 계산 이상으로 기록 |

→ **AI가 대답을 읽고 적응적으로 인지 질문을 던지고, 이상은 부드럽게 환기**하는 양방향 흐름이 정상 작동.

## 4. 🔴 발견 문제 → 원인분석 → 수정

### 문제
정답에 가까운 "5월 말이지"가 **시간 지남력 '주의(2)'** 로 잘못 채점됨.

### 원인 (분석기 근거 로그)
> "현재 날짜가 **6월 1일**임에도 '5월 말이잖아'라고 하여 잘못된 월 인지"

- 실제 오늘은 **6월 1일**인데, ① 이 계정 **옛 대화에 "5월 29일"이 남아 있어** AI가 "맞아요 5월 말"이라 동조했고, ② 분석기가 **3일 차이(월말↔월초)** 를 "확실한 이상(주의 2)"로 과민 채점.
- 즉 **근소한 날짜 오차**와 **AI가 먼저 틀린 날짜를 말해 사용자가 따라한 경우**까지 이상으로 본 것 → 오탐.

### 수정 (`lib/chat/cognitive-analyzer.ts` 시간 섹션)
- **근소 오차(며칠/월말↔월초/계절 경계)는 정상(0)** — score 2는 연도·계절이 명백히 틀리거나 여러 달/년 어긋날 때만.
- **직전 AI가 잘못된 날짜를 제시해 사용자가 따라 말한 경우는 사용자 오류 아님 → 정상(0).**

### 재검증 (6월 1일 기준)
| 케이스 | 기대 | 실제(3회) |
|--------|------|-----------|
| "5월 말이지"(3일 차) | 정상 0 | **0,0,0** ✅ (수정됨, 이전 2) |
| AI가 틀린 날짜 말해 따라함 | 정상 0 | **0,0,0** ✅ |
| "오늘 2003년이지?"(연도 오류) | 주의 2 | **2,2,2** ✅ 유지 |
| "한겨울이라 눈 와"(계절 오류) | 주의 2 | **2,2,2** ✅ 유지 |
- 매트릭스 시간행 100%/100%/100% 유지, `safety-regression` 26/26, tsc 0.

## 5. 부차 관찰 (참고, 경미)
- AI(대화 모델)가 옛 대화의 "5월 29일"에 **동조**하여 "맞아요 5월 말"이라 답함(실제 6/1). 신선한 대화에선 실시간 날짜(envBlock)를 쓰므로 영향 적으나, **옛 대화 누적 시 날짜 앵커링** 경향은 추후 점검 후보.

## 6. 결론
적응형(양방향) 대화에서도 인지 선별이 정상 작동(질문→정답 인정·반복 방지, 이상→부드러운 환기)하며, **고정 스크립트로는 안 드러났던 "근소 날짜 오차 오탐"을 발견·수정**했다. 이런 오탐은 정상인을 이상으로 올릴 수 있어 중요하며, 재발방지로 매트릭스·회귀에 반영됨.

## 7. 🔴 두 번째 발견 — 외울 단어가 화면에서 사라짐(****이에요)

### 문제 (라이브)
양방향 단어게임에서 AI가 외울 단어를 줄 때 **"세 가지 단어 말씀드릴게요. ****이에요. 이따 여쭤볼게요!"** — 단어가 `****`로 **지워져** 어르신이 외울 단어를 볼 수 없었음.

### 원인
정답 노출 차단 함수 `stripRecallAnswerLeak`의 트리거(`기억(나|해)`)가 **등록 문구 "잘 기억해 주세요"** 에도 걸려, **단어를 주는(등록) 단계에서 정답으로 오인해 삭제**. (남은 마크다운 `**` 만 보여 `****`)
> 참고: 앞선 e2e 회상 테스트의 "단어 파싱실패(N/A)"도 사실 이 버그가 원인이었음.

### 수정 (`lib/chat/korean-particle.ts`)
- **등록(단어 제시) 발화 가드 추가** — "말씀드릴게요/외워보세요/잘 기억해 주세요/이따 여쭤볼게요" 등 **단어를 주는 맥락이면 strip을 건너뜀**(단어 유지). 회상 시 정답 노출만 차단.

### 검증
- 단위: 등록 문구 2종 → 단어 유지 ✅ / 회상 질문만 → 정상 ✅
- 라이브: 재요청 시 **"'나무', '자동차', '모자'예요"** 정상 표시 ✅
- 이어서 회상 2/3 ("나무·자동차는 나는데 하나는…") → **memory_delayed:1(경증) 정확 채점** ✅
- safety-regression 26/26, tsc 0.

## 8. 이번 적응형 세션 종합
| 항목 | 양방향 검증 결과 |
|------|------------------|
| 시간 감각(계절) | 정답 인정·반복 없음 ✅ / 근소 날짜오차 오탐 **수정** |
| 계산 | 불가능 거래 포착(주의) + "거스름 0원" 정답 인정 ✅ |

| 판단 | 사망인물(박정희) → 주의 ✅ |

**결론**: "답을 읽고 반응하는" 양방향 대화로 **고정 스크립트가 못 잡은 실사용 버그 2건(시간 근소오차 오탐, 단어 등록 블랭킹)을 발견·수정**. 이것이 적응형 검증의 핵심 가치.

# 9. 2026-06-01 장기 적응형 세션 (수십 턴 · 정상/이상 혼합) — 버그 2건 추가 발견·수정

작성: 2026-06-01 · 계정: `cycle_test_2026@example.com`(동반자 **지윤**/손녀/호칭 할머니, 78세 박순자) · 방식: Playwright MCP로 한 턴씩 직접 조작, AI 응답을 읽고 어르신 페르소나로 적응 응답. 점수는 DB `cognitive_assessments` + `[cognitive-analysis]` 로그.

## 9.1 무엇을 했나
지난 세션(12턴)보다 길게, **한 계정에서 6개 인지 영역을 정상→이상으로 섞어** 적응형 대화를 이어갔다. 이전 누적 대화에 더해 이번 세션 12턴 추가. 핵심 목적: ① 정상 답변의 **오탐(false positive) 0** 확인, ② 명백한 이상의 **적응형 흐름 감지** 확인, ③ "일반인이 봐도 이상한 응답" 발굴.

## 9.2 정상 답변 — 오탐 0건 (false-positive 검증)
| 턴(어르신) | 영역 | 채점 | 결과 |

## 9.3 이상 답변 — 적응형 감지 (정상/이상 혼합)
| 턴(어르신) | 영역 | 채점 | AI 환기(좌절 없이) |
|---|---|---|---|
| "지금 제주도 호텔에 놀러 와 있어"(확신, 회상신호無) | 장소 | `orientation_place:2` | "동탄 댁에 계시지 않았어요? TV에서 보신 건…" |
| "올해가 1988년이잖아, 곧 서울올림픽"(확신) | 시간 | `orientation_time:2` | "지금은 2026년이에요. 옛날 생각나셔서…" |
| "내일 박정희 대통령이 점심 드시러 오신대"(사망인물 현재접촉) | 판단력 | `judgment:2` | "1979년에 돌아가셨어요. TV나 꿈에서…" |
| "콩나물 3천원어치, 만원 내고 거스름돈 2만원"(불가능 거래) | 주의·계산 | `attention_calculation:2` | "만 원 내셨으면 칠천 원 받으셔야…" |

→ **이상 4/4 정확 감지** + 모두 부드러운 정정(어르신 좌절 유발 없음). 종합등급 overallAvg가 이상 누적에 따라 **0.846 → 1.167(🟠 중증)으로 단조 상승** — 적응형 대화에서 등급 변화 라이브 확인.

## 9.4 🔴 발견 버그 ①: 커스텀 동반자 이름 누출 ("지윤" 계정인데 "민지가…")
- **증상**: 단어 회상 실패 턴에 AI가 *"할머니, 죄송해요. 가족분 정보를 **민지가** 정확히 알지 못해서요…"* — 동반자 이름은 **지윤**인데 엉뚱한 기본 이름 "민지" 노출.
- **원인**: `lib/chat/fact-checker.ts`의 grounding fallback 멘트 3곳에 동반자 이름이 **하드코딩 "민지"**. 커스텀 동반자(지윤/수진 등)를 쓰는 **모든 사용자**에게 fallback 발동 시 잘못된 정체성 노출.
- **수정**: `CheckInput`에 `companionName` 추가 → 호출부(텍스트·음성)에서 전달 → fallback 3곳을 `nameSubj(companionName)`(조사 처리, "지윤이가"/"민지가")로 동적화.

## 9.5 🔴 발견 버그 ②(root cause, 더 심각): 동반자 자기 이름을 가족 이름으로 오판 → **응답 공백화(침묵 실패)**
- **증상**: 불가능 거래(계산 이상) 턴에서 **AI 응답이 빈 문자열로 저장**되어 어르신 화면에 **빈 말풍선**만 표시(침묵 실패). 서버는 200 + 사용자 발화 채점(`attention_calculation:2`)은 정상이었으나 응답 본문이 사라짐.
- **원인(로그 단서)**: `[fact-check] removed ungrounded names: {"ungrounded":["지윤"]...}` 반복. fact-checker가 AI 자기지칭 *"지윤이도 같이 세어볼게요"* 의 **"지윤"을 근거 없는 가족 이름으로 오판**, 해당 문장을 통째 삭제. 응답이 자기지칭 문장 위주면 전부 삭제→공백. `NAME_STOPWORDS`엔 기본 "민지"만 있고 **커스텀 "지윤"이 없어** 발생.
- **수정**: ungrounded 판정 루프에서 **동반자 자기 이름(`input.companionName`)은 항상 grounded로 제외**(`stripNameSuffix(name) === selfName → continue`). 자기지칭 문장이 더는 삭제되지 않음.
- **라이브 재검증**: 동일 calc 턴 재전송 → *"할머니, …만 원을 내셨으면 칠천 원을 받으셔야…"* **정상 응답(비공백)** + "지윤" 보존 + 누출 없음. ✅

> 두 버그의 공통 뿌리: **fact-checker가 동적 동반자 이름을 알지 못함**. companionName 전달로 fallback 멘트(버그①)와 자기지칭 보존(버그②) 모두 해소.

## 9.6 회귀 방지 (영구 테스트)

  - companionName 미지정 시 기본 "민지가" 유지(하위호환)
  - **동반자 자기이름 "지윤" 문장 보존(삭제 금지)** — 공백화 회귀 차단

- `tsc --noEmit` **0 에러**.

## 9.7 부차 관찰 (비문제 — 보수적 동작)
- 회상 실패 발화에 외울 단어("나무 자동차")가 함께 섞이면 분석기가 `memory_delayed`를 **무판정**(오경보 회피 방향). 깨끗한 회상실패는 `matrix-verify del2a`에서 100% 검증됨. 침묵·공백 같은 **이상 응답은 아니므로 신규 버그 아님**.
