# 적응형(양방향) 대화 검증 리포트

작성: 2026-06-01 · 방식: Playwright로 실제 앱에 접속, **AI 응답을 읽고 어르신 역할로 그에 맞춰 답하는 진짜 양방향 대화**(스크립트 고정 발화 X)

---

## 1. 무엇을 했나
지금까지는 "정해둔 문장을 던지는" 테스트였다면, 이번엔 **AI가 한 말을 읽고 → 어르신처럼 그에 맞춰 다음 말을 이어가는** 자연스러운 대화로 검증했다. (계정: 페르소나 할머니 / 동반자 "지윤")

## 2. 대화 흐름 (요약)
| 턴 | 어르신(테스터) | AI(지윤) 반응 | 관찰 |
|----|----------------|----------------|------|
| 1 | "오늘 날씨 좋아 기분 좋네" | 공감 + **"지금 계절이 어느 때쯤?"** | AI가 자연스럽게 시간 감각 질문 |
| 2 | "봄 끝나가고 곧 여름이지, 5월 말" | "맞아요!" + 다음 화제(여름 음식) | 정답 인정, **계절 재질문 안 함** |
| 3 | "여름엔 콩국수지" | 콩국수 설탕/소금 | 자연 대화 |
| 4 | "만원짜리 두부 샀는데 거스름 2만원 받았어" | **"만 원 내셨는데 이만 원 돌려받으신 거예요?"** | **불가능한 거래를 부드럽게 포착(좌절 없이)** |
| 5 | "응 만원 내고 이만원 받았어" | (확인) | 계산 이상으로 기록 |

→ **AI가 대답을 읽고 적응적으로 인지 질문을 던지고, 이상은 부드럽게 환기**하는 양방향 흐름이 정상 작동.

## 4. 🔴 발견 문제 → 원인분석 → 수정

### 문제
정답에 가까운 "5월 말이지"가 **시간 지남력 '주의(2)'** 로 잘못 채점됨.

### 원인 (분석기 근거 로그)
> "현재 날짜가 **6월 1일**임에도 '5월 말이잖아'라고 하여 잘못된 월 인지"

- 실제 오늘은 **6월 1일**인데, ① 이 계정 **옛 대화에 "5월 29일"이 남아 있어** AI가 "맞아요 5월 말"이라 동조했고, ② 분석기가 **3일 차이(월말↔월초)** 를 "확실한 이상(주의 2)"로 과민 채점.
- 즉 **근소한 날짜 오차**와 **AI가 먼저 틀린 날짜를 말해 사용자가 따라한 경우**까지 이상으로 본 것 → 오탐.

### 수정 (`lib/chat/cognitive-analyzer.ts` 시간 섹션)
- **근소 오차(며칠/월말↔월초/계절 경계)는 정상(0)** — score 2는 연도·계절이 명백히 틀리거나 여러 달/년 어긋날 때만.
- **직전 AI가 잘못된 날짜를 제시해 사용자가 따라 말한 경우는 사용자 오류 아님 → 정상(0).**

### 재검증 (6월 1일 기준)
| 케이스 | 기대 | 실제(3회) |
|--------|------|-----------|
| "5월 말이지"(3일 차) | 정상 0 | **0,0,0** ✅ (수정됨, 이전 2) |
| AI가 틀린 날짜 말해 따라함 | 정상 0 | **0,0,0** ✅ |
| "오늘 2003년이지?"(연도 오류) | 주의 2 | **2,2,2** ✅ 유지 |
| "한겨울이라 눈 와"(계절 오류) | 주의 2 | **2,2,2** ✅ 유지 |
- 매트릭스 시간행 100%/100%/100% 유지, `safety-regression` 26/26, tsc 0.

## 5. 부차 관찰 (참고, 경미)
- AI(대화 모델)가 옛 대화의 "5월 29일"에 **동조**하여 "맞아요 5월 말"이라 답함(실제 6/1). 신선한 대화에선 실시간 날짜(envBlock)를 쓰므로 영향 적으나, **옛 대화 누적 시 날짜 앵커링** 경향은 추후 점검 후보.

## 6. 결론
적응형(양방향) 대화에서도 인지 선별이 정상 작동(질문→정답 인정·반복 방지, 이상→부드러운 환기)하며, **고정 스크립트로는 안 드러났던 "근소 날짜 오차 오탐"을 발견·수정**했다. 이런 오탐은 정상인을 이상으로 올릴 수 있어 중요하며, 재발방지로 매트릭스·회귀에 반영됨.

## 7. 🔴 두 번째 발견 — 외울 단어가 화면에서 사라짐(****이에요)

### 문제 (라이브)
양방향 단어게임에서 AI가 외울 단어를 줄 때 **"세 가지 단어 말씀드릴게요. ****이에요. 이따 여쭤볼게요!"** — 단어가 `****`로 **지워져** 어르신이 외울 단어를 볼 수 없었음.

### 원인
정답 노출 차단 함수 `stripRecallAnswerLeak`의 트리거(`기억(나|해)`)가 **등록 문구 "잘 기억해 주세요"** 에도 걸려, **단어를 주는(등록) 단계에서 정답으로 오인해 삭제**. (남은 마크다운 `**` 만 보여 `****`)
> 참고: 앞선 e2e 회상 테스트의 "단어 파싱실패(N/A)"도 사실 이 버그가 원인이었음.

### 수정 (`lib/chat/korean-particle.ts`)
- **등록(단어 제시) 발화 가드 추가** — "말씀드릴게요/외워보세요/잘 기억해 주세요/이따 여쭤볼게요" 등 **단어를 주는 맥락이면 strip을 건너뜀**(단어 유지). 회상 시 정답 노출만 차단.

### 검증
- 단위: 등록 문구 2종 → 단어 유지 ✅ / 회상 질문만 → 정상 ✅
- 라이브: 재요청 시 **"'나무', '자동차', '모자'예요"** 정상 표시 ✅
- 이어서 회상 2/3 ("나무·자동차는 나는데 하나는…") → **memory_delayed:1(경증) 정확 채점** ✅
- safety-regression 26/26, tsc 0.

## 8. 이번 적응형 세션 종합
| 항목 | 양방향 검증 결과 |
|------|------------------|
| 시간 감각(계절) | 정답 인정·반복 없음 ✅ / 근소 날짜오차 오탐 **수정** |
| 계산 | 불가능 거래 포착(주의) + "거스름 0원" 정답 인정 ✅ |
| 기억 | 단어 등록 표시 **수정** + 회상 2/3 → 경증(1) ✅ |
| 판단 | 사망인물(박정희) → 주의 ✅ |

**결론**: "답을 읽고 반응하는" 양방향 대화로 **고정 스크립트가 못 잡은 실사용 버그 2건(시간 근소오차 오탐, 단어 등록 블랭킹)을 발견·수정**. 이것이 적응형 검증의 핵심 가치.
