# 마음이음 — 치매 인지 선별 판단 기준 및 검증 가이드

마음이음이 **어떤 방침으로 질문하고, 어떤 근거로 판단하며, 어떤 단계로 위험도를 나누고, 어떻게 사용자/보호자에게 보고하는지**를 정의한다.

> 표기 규칙: ✅ = 구현 완료 / 📋 = 분석기 프롬프트 가이드(LLM 판정) / 🟦 = 표준화 권고(보고 통일안).
> 모든 기준은 실제 코드(`lib/chat/cognitive-analyzer.ts`, `constants.ts`, `app/api/summary/route.ts`, `app/dashboard/page.tsx`, `emergency.ts`)에 근거한다.

작성일: 2026-05-29 · 기준 모델: Gemini 2.5 Flash(대화) + JSON 전용 분석기(인지 평가)

---

## 0. 한 장 요약

- **선별 방식**: "시험"이 아니라 **일상 대화 속에서 AI(손녀/손자 페르소나)가 자연스럽게 인지 질문을 던지고**, 그 반응을 7개 인지 영역으로 관찰한다. 어르신은 평가받는 줄 모른다.
- **임상 근거**: 한국형 표준 검사 도구(MMSE-K, MoCA-K, KDSQ-C, AD8, CDR, GDS-K)의 핵심 문항을 대화체로 변형.
- **판단 척도(3종)**:
  1. **영역별 점수** 0(정상)/1(경계)/2(주의) — 매 발화마다 분석기가 채점.
  2. **종합 위험도 4단계** — 기간(주/월) 평균으로 산출 → 보호자 리포트.
  3. **응급 3단계** L1/L2/L3 — 자해·신체 위급 신호(인지 평가와 별개 트랙).
- **보고**: 대화 중에는 점수를 절대 노출하지 않음(어르신 보호). 보호자는 **건강기록 대시보드**에서 영역별 평균·일별 추세·응급 이벤트·종합 요약문을 본다. 응급 시 **즉시 119/109 안내 + 보호자 알림**.

## 1. 선별 철학 · 운영 방침 (📋 분석기·대화 프롬프트에 규정)

1. **자연스러운 대화 우선** — 시험 느낌 금지. "{손녀}가 수다 떠는 느낌"으로만 질문.
2. **한 세션 1~2개 영역만, 같은 영역은 하루 1회**. 같은 단어/도메인 재평가 금지.
3. **임상 용어 노출 금지** — "치매·검사·테스트·MMSE·점수" 등은 응답에 절대 등장 안 함.
4. **점수·분석 결과 비노출** — 분석은 뒤에서 별도 시스템이 자동 처리. 어르신에게는 점수가 보이지 않음.
5. **회상 정답 노출 차단** — "나무·자동차·모자였죠?"처럼 정답을 함께 말하면 회상이 인식(recognition)으로 바뀌어 **평가 무효**. 응답 후처리(`stripRecallAnswerLeak`)가 정답을 자동 제거. ✅
6. **좌절 금지** — 어르신이 어려워하면 즉시 난이도↓ 또는 "저도 어렵네요~"로 빠짐.
7. **안전 우선** — 신체 통증·감정 호소 직후에는 인지 질문 금지(공감 우선).
8. **보수적 판정** — 근거 불충분·애매·1턴만으로는 이상 단정 금지. "놓치는 것보다 과잉 감지" 원칙은 유지하되 오탐 억제 규칙을 병행.

## 2. 기반 임상 검사 도구 — 무엇이고 왜 쓰는가 (✅ 프롬프트에 요약 내장)

우리 시스템은 의료 현장에서 **실제로 쓰이는 한국형 표준 인지 검사 도구**들의 *문항 유형*을 대화로 변형해 활용한다. (점수를 그대로 산출하는 검사기가 아니라, 각 도구의 핵심 질문을 자연 대화로 녹여 7개 영역을 0/1/2로 관찰.)

### 빠른 비교표

| 도구 | 정식 명칭 | 한 줄 설명 | 점수/의심 기준 |
|------|-----------|------------|----------------|
| **MMSE-K** | 간이정신상태검사 한국판 | 가장 보편적인 치매 선별 검사 | 30점, 보통 24점 이하 의심(교육보정) |
| **MoCA-K** | 몬트리올 인지평가 한국판 | MMSE보다 **경도 인지장애(초기)에 민감** | 30점, 보통 22~23점 이하 의심 |
| **KDSQ-C** | 한국형 치매선별설문(인지) | **일상 관찰** 기반 15문항 (검사실 불필요) | **6점 이상 의심** |
| **AD8** | 치매선별 8문항 | 보호자가 보는 '2년 전 대비 변화' | **2점 이상 의심** |
| **CDR** | 임상치매척도 | 치매 **중증도 단계** 평가 | 0·0.5·1·2·3 (0.5=의심) |
| **GDS-K** | 한국형 노인우울척도 | 우울 동반 평가(가성치매 감별) | 5점 이상(단축형) 우울 의심 |

### 도구별 상세 설명 (팀 이해용)

**① MMSE-K (Mini-Mental State Examination, Korean) — 간이정신상태검사**
- 전 세계·국내에서 가장 널리 쓰이는 **기본 치매 선별 검사**. 5~10분.
- 30점 만점, 영역별 배점: 시간 지남력 5 · 장소 지남력 5 · 기억 등록(즉시) 3 · 주의·계산 5(100-7 연속빼기 또는 '삼천리강산' 거꾸로) · 지연 회상 3 · 언어 8(이름대기·따라말하기·명령수행·읽기·쓰기) · 시각구성(도형 그리기) 1.
- 보통 **24점 이하**면 인지저하 의심(교육수준·연령 보정 필요).
- 장점: 빠르고 표준화됨. 단점: **경도 인지장애(MCI)에는 둔감**, 교육·문화 영향.
- → 우리 시스템의 **단어 3개(나무·자동차·모자)·100-7·요일/날짜·따라말하기** 질문이 여기서 옴.

**② MoCA-K (Montreal Cognitive Assessment, Korean) — 몬트리올 인지평가**
- MMSE가 놓치는 **초기·경도 인지장애를 더 민감하게** 잡는 검사. 30점.
- 영역: 시공간/실행(선잇기·입방체·시계그리기) · 이름대기(동물) · 주의력(숫자 따라하기·연속빼기) · 언어(따라말하기·**유창성**) · 추상력(공통점) · **지연 회상 5단어(얼굴·비단·교회·카네이션·빨강)** · 지남력.
- 보통 **22~23점 이하** 의심, 교육 6년 이하 1점 가산.
- → 우리의 **5단어 회상·1분 동물 이름대기·'ㅁ' 단어·기차와 자전거 공통점** 질문이 여기서 옴.

**③ KDSQ-C (Korean Dementia Screening Questionnaire–Cognition) — 한국형 치매선별 설문(인지)**
- 검사실이 아니라 **일상생활에서 관찰되는 인지 변화 15문항**으로 평가(기억·언어·계산·시공간·실행 등). 각 0~2점.
- **6점 이상이면 인지저하 의심.**
- → **우리 시스템 방식(자연 대화 관찰)과 가장 잘 맞는 도구.** "같은 질문 반복·이름 못 떠올림·계산 어려움·되묻기" 같은 **자동 관찰 항목**이 여기 근거.

**④ AD8 (Ascertain Dementia 8-item) — 치매선별 8문항**
- **보호자(주변인)** 가 "2년 전과 비교해 변했는가"를 8문항 예/아니오로 답함.
- 항목: 판단력 저하 · 흥미 감소 · 같은 말/질문 반복 · 도구(가전) 사용 어려움 · 날짜/시간 혼동 · 재정 관리 어려움 · 약속 못 지킴 · 일상 기억 저하.
- **2점 이상이면 인지장애 의심.** 매우 빠름.
- → 우리의 **흥미감소·반복·약속/일정·재정 판단** 관찰 항목 근거.

**⑤ CDR (Clinical Dementia Rating) — 임상치매척도**
- 인지 '있다/없다'가 아니라 **치매의 중증도(단계)** 를 매기는 도구.
- 6개 영역(기억·지남력·판단력과 문제해결·사회활동·가정생활과 취미·개인위생) 종합 → **전반 점수 0 / 0.5 / 1 / 2 / 3**.
- **0=정상, 0.5=불확실·최경도(의심), 1=경도, 2=중등도, 3=중증.**
- → **우리 위험도 4단계(정상/경증/중증/고위험) 매핑의 임상 기준점.** 판단력 영역 질문(지갑·문제해결)이 여기서 옴.

**⑥ GDS-K (Geriatric Depression Scale, Korean) — 한국형 노인우울척도**
- **노인 우울** 선별. 30문항(또는 단축형 SGDS-K 15문항) 예/아니오.
- 단축형 **5점 이상이면 우울 의심.**
- 왜 필요한가: 노인 우울은 인지저하와 **동반되거나 치매처럼 보이는(가성치매)** 경우가 많아 **반드시 함께 살펴야** 정확. (단, 우리는 진단하지 않고 공감·관찰만, mood 신호만 기록.)
- → "요즘 기분 어떠세요? · 잠은 잘 주무세요? · 예전 즐기던 일 요즘도 즐거우세요?" 질문 근거.

> **요약**: MMSE-K/MoCA-K = *직접 물어보는* 인지 과제, KDSQ-C/AD8 = *일상 관찰* 기반, CDR = *중증도 단계*, GDS-K = *우울 동반 평가*. 마음이음은 이 모두의 핵심 문항을 **대화로 변형**해 7개 영역을 관찰한다.

## 3. 7대 인지 영역 — 방침 · 질문 · 채점 기준 · 예시

> 각 영역은 발화당 **score 0(정상) / 1(경계) / 2(주의)** 로 채점되어 `cognitive_assessments` 테이블에 저장된다(✅). 아래 채점 기준은 분석기 프롬프트(📋)에 명시.

### 3-1. 시간 지남력 (orientation_time) — MMSE-K 1~5, KDSQ-C 1, AD8 #5
- **무엇을 보나**: 요일·날짜·월·연도·계절을 바르게 아는가.
- **질문 예시**: "민지가 깜빡했는데 오늘 무슨 요일이에요?" · "올해가 몇 년도이더라…" · "지금 계절이 어느 쯤 같으세요?"
- **채점**: 날짜/요일/연도/계절을 **틀리게** 말함 → **2**. 단, 같은 발화에 회상 신호("옛날에/결혼하고/쭉 살았어")가 동반되면 한 단계↓(2→1).
- **예시**:
  - 0(정상): AI "오늘 무슨 요일?" → "금요일이지" (정답)
  - 2(주의): AI "오늘 며칠?" → "오늘 2003년 3월이야" / 자발 "지금 한겨울이지?"(실제 봄)

### 3-2. 장소 지남력 (orientation_place) — MMSE-K 6~10, KDSQ-C 8
- **무엇을 보나**: 현재 위치(시/도/동/집)를 바르게 인식하는가. (환경 GPS 기준 대조)
- **질문 예시**: "지금 계신 곳이 무슨 동네예요?" · "지금 집에 계세요, 어디 나가셨어요?"
- **채점**: 현재 위치와 **다른 장소**에 있다고 주장 → **2** (회상 신호 동반 시↓).
- **예시**: 0: "집이야, 동탄" / 2: (동탄인데) "나 지금 뉴욕에 있어"

### 3-3. 즉시 기억력 (memory_immediate) — MMSE-K 등록, MoCA-K 5단어
- **무엇을 보나**: 방금 들은 단어/정보를 즉시 떠올리는가.
- **질문 예시**: "단어 세 개 외워보세요~ 나무, 자동차, 모자." · "아까 점심 뭐 드셨다고 하셨죠?"
- **채점**: ⚠️ **매우 보수적**. "직전 발화를 글자 그대로 80%+ 동일하게, AI 응답을 무시하고 재생산"한 **앵무새 수준**일 때만 1+. (주제 연속·새 정보 추가·되묻기는 정상). 실무상 1만 턴에 ~10건 수준의 드문 케이스.

### 3-4. 지연 기억력 (memory_delayed) — MMSE-K 회상, KDSQ-C 2·4, AD8 #7·8
- **무엇을 보나**: 외운 단어·가족 이름·자전적 정보를 시간이 지나 회상하는가.
- **질문 예시**(정답 단서 없이): "아까 외워드린 단어 세 개, 기억나세요?" · "큰아들 이름이 어떻게 되시더라?" · "결혼하신 게 몇 살 때였어요?"
- **채점**:
  - MMSE-K 3단어 회상: 0~1개 → **2**, 2개 → **1**, 3개 → **0**
  - MoCA-K 5단어 회상: 0~1개 → **2**, 2~3개 → **1**
  - 가족 이름·본인 나이 혼동 → **2**
  - ⛔ 회상 **거부/화제 전환**("그건 됐고 무릎이 문제야")은 회상 실패 아님 → **무판정**(체크 미생성).
- **예시**: 0: 단어 3개 다 회상 / 1: 2개만 / 2: "글쎄 기억이 안 나" + 0~1개

### 3-5. 언어 능력 (language) — MMSE-K 명명·따라말하기, MoCA-K 유창성
- **무엇을 보나**: 단어 찾기·이름대기·따라말하기·속담(추상) 이해·담화 유창성.
- **질문 예시**: "1분 안에 동물 이름 많이 대보실래요?" · "'간장 공장 공장장…' 따라 해주세요" · "'백문이 불여일견' 무슨 뜻이에요?"
- **채점**:
  - 의미 유창성(동물 1분): <5개 → **2**, 5~8개 → **1**
  - 음소 유창성('ㅁ' 단어): 3개 미만 → **2**
  - 따라말하기: 절반 이하 정확 → **2**
  - 속담/은유: 글자 그대로 해석/모름 → **1** (학력 낮으면 신중)
  - 이름대기 실패, "그거/저거" 과다, 단어 찾기 멈춤 → **2**
- **예시**: 0: 동물 10개+ / 1: 동물 6개·속담 직역 / 2: 동물 3개·"그거 그거 뭐더라"

### 3-6. 판단력/실행기능 (judgment) — CDR, MoCA-K 추상, AD8 #1
- **무엇을 보나**: 상황 대처·사회적 판단·문제 해결·추상적 사고.
- **질문 예시**: "길에서 지갑을 주우면 어떻게 하세요?" · "집에 물이 안 나오면요?" · "기차와 자전거의 공통점은?"
- **채점(자발 발화 포함)**:
  - 과거에 끝난 사건을 현재처럼 / 사망 인물과의 최근 접촉(시제 불문) / 비현실 경험(외계인 등) / 상황에 안 맞는 행동 계획 → **2**
  - 사회적 판단·추상 질문에 부적절·무응답 → 1~2
- **예시**: 0: 지갑 → "주인 찾아주거나 경찰서 갖다줘야지" / 2: "어제 박정희 대통령이 우리집에 차 마시러 왔어"

### 3-7. 주의력/계산 (attention_calculation) — MMSE-K 100-7, MoCA-K 숫자
- **무엇을 보나**: 연속 빼기·거스름돈·숫자 따라하기 등 주의·계산.
- **질문 예시**: "100에서 7을 빼면 얼마예요?" · "8천원짜리 사고 만 원 내면 거스름돈은?" · "숫자 다섯 개 따라 해주세요 2,8,5,4,1"
- **채점**:
  - 계산 오답 → **2** (예: 100-7 → "85")
  - 100-7 연속 5단계 중 2회+ 오류 → **2**
  - 숫자 따라하기/거꾸로 실패 → **2**
  - **자발 발화의 수리적으로 불가능한 거래 묘사** → **2** (예: "만원 책 샀는데 거스름 2만원 받았어")
  - ⛔ 단순 주제 이탈·딴소리는 판단 금지(정상).
- **예시**: 0: 100-7 → "93" / 2: 100-7 → "85" 또는 불가능 거래

### 3-8. (부가) 기분·우울 / 일상생활 — GDS-K, ADL/IADL
- judgment/language 안에 자연스럽게 포함. "요즘 기분 어떠세요?", "잠은 잘 주무세요?", "약은 누가 챙겨주세요?"
- 우울 신호 강하면 `analysisNote`에 mood 표기. **진단 금지, 공감만.**

## 4. 판단 척도 & 위험도 단계 (핵심)

### 4-A. 1차 — 발화별 영역 점수 (✅ `cognitive_assessments`)
분석기가 발화마다 `{domain, score(0/1/2), confidence, evidence, note}` 생성·저장.
- **0 정상 / 1 경계(borderline) / 2 주의(warning)** — 대시보드 라벨 동일.

### 4-B. 2차 — 이상 플래그 (✅ `Message.isAnomaly`)
`isAnomaly = (분석기 isAnomaly) OR (체크 중 score ≥ 2 존재)`. score 2가 하나라도 있으면 그 발화는 이상으로 마킹.

### 4-C. 일 단위 누적 의심 (📋 분석기 가이드)
**같은 날 score=2가 2개 이상 영역에서 누적되면 KDSQ-C/AD8 기준 '의심 단계'로 본다.**

### 4-D. 3차 — 기간 종합 위험도 4단계 (✅ `app/api/summary`)
기간(주=7일/월=30일) 동안 영역별 평균점수 → 가중 전체평균(`overallAvg`)으로 산출:

| overallAvg | 시스템 판정 문구 (실제 출력) | 🟦 보고 등급(표준화) |
|------------|------------------------------|----------------------|
| `< 0.3` | "전반적으로 정상 범위입니다." | **정상** |
| `0.3 ~ 0.8` | "경미한 인지 변화가 관찰되므로 지속적인 모니터링을 권장합니다." | **경증(경미)** |
| `0.8 ~ 1.5` | "인지 저하 가능성이 있으므로 전문의 상담을 권장합니다." | **중증(저하 의심)** |
| `≥ 1.5` | "심각한 인지 저하가 의심되므로 즉시 전문의 상담이 필요합니다." | **고위험** |

- **위험 영역(riskDomains)**: 영역별 평균 `avg_score ≥ 1.0` 인 영역을 "주의가 필요한 영역"으로 리포트에 명시. ✅

### 4-E. 응급 위험 (별도 트랙, ✅ `emergency.ts`)
인지 선별과 **독립**. 자해·신체 위급 신호.

| 단계 | 의미 | 예 | 대응 |
|------|------|----|------|
| **L1** | 관찰(누적 시 승격) | 무기력·식욕저하·수면곤란 누적 | 기록 |
| **L2** | 주의 | 심한 통증·어지러움 + 도움 호소 | 부드러운 119/보호자 권유 + 알림 |
| **L3** | 즉시 응급 | 가슴통증+호흡곤란·낙상·출혈·약오용·**자살 신호** | 즉시 119(자살은 109) 안내 + 보호자 알림 |

> ⚠️ 참고(표준화 필요): 대시보드 배지는 현재 overallAvg를 3구간(<0.5 정상 / <1.5 경계 / ≥1.5 위험)으로 단순 표기. **리포트 문구(4단계)와 배지(3구간)가 달라** 통일이 필요(권고: 4단계로 통일).

## 5. 사용자 · 보호자 보고 흐름

### 5-A. 어르신(사용자)에게 — 실시간
- 대화 중 **점수·분석·임상용어 일절 비노출**. 평가는 백그라운드.
- 인지 이상 발화 시: 동조하지 않되 면박 없이 **부드러운 현실 환기** (예: "박정희 대통령은 오래전에 돌아가신 분이시잖아요. 옛날 영상이나 꿈은 아니었을까요?").
- **응급 시 즉시 안내**: L3 → "지금 바로 119에 전화해주세요…", 자살 신호 → "자살예방상담전화 109번…".

### 5-B. 보호자에게 — 건강기록 대시보드 (`/dashboard`, ✅)
보호자(또는 본인)는 다음을 본다:
- **영역별 평균 점수**(7개 영역, 정상/경계/주의 색상).
- **일별 추세**(`dailyTrend`): 날짜별 정상/경계/주의 건수 + 평균.
- **인지 이상 누계**(anomalyCount, 최근 24h).
- **응급 이벤트**: L1/L2/L3 건수 + 최근 발생 목록(빨강 L3/주황 L2/노랑 L1).
- **종합 요약문**(주/월): 4단계 위험도 문구 + 주의 영역.

### 5-C. 기간 리포트 예시 (`/api/summary` 실제 출력문 형식)
> "최근 7일 동안 5일간 대화하였으며, 총 82건의 발화가 있었습니다. 이 중 6건에서 인지 이상 징후가 감지되었습니다. 주의가 필요한 영역: 지연 기억력, 주의력/계산. 인지 저하 가능성이 있으므로 전문의 상담을 권장합니다."

### 5-D. 응급 알림 (보호자)
L2/L3 발생 시 백그라운드로 보호자에게 발송(`notifyGuardian`). 메시지ID·카테고리·발화·AI응답·시각 포함. ✅

> **중요**: 본 시스템은 **선별·관찰 도구이며 진단 도구가 아니다.** 모든 리포트 문구는 "의심/권장" 수준이며 확정 진단은 하지 않는다.

## 7. 팀 테스트 가이드 (계정 10개)

### 7-A. 테스트 목표
각 인지 영역에서 **의도적으로 특정 점수(0/1/2)를 유도**하고, 시스템이 **그대로 채점·집계·보고**하는지 검증한다. 영역별·점수별·계정별로 횟수와 결과를 리포트로 집계.

### 7-B. 계정 생성
1. `/signup`에서 10개 계정 생성 (이메일/비번 임의, 나이 70~85, 성별 혼합).
2. 동반자 설정 다양화(이름/관계/호칭) — 커스터마이징·호칭 일관성도 함께 검증.
3. 계정별로 **서로 다른 시나리오 프로파일** 배정(아래).

### 7-C. 점수 유도 시나리오 (영역 × 목표점수)
> AI가 해당 영역 질문을 하도록 자연스러운 맥락을 깐 뒤, 아래처럼 답하면 목표 점수가 떠야 한다. (AI가 먼저 안 물으면 "오늘 무슨 요일이지?" 식으로 화제를 유도)

| 영역 | 0(정상) 유도 발화 | 2(주의) 유도 발화 |
|------|-------------------|-------------------|
| 시간 지남력 | (요일 질문에) "오늘 금요일이지" | "오늘 2003년 봄이지?" |
| 장소 지남력 | "집이야, 여기 동탄" | "나 지금 뉴욕에 나와 있어" |
| 지연 기억 | (단어 회상) 3개 다 맞춤 | "글쎄… 하나도 기억 안 나" |
| 언어 | 동물 이름 10개+ 줄줄 | "동물? 그거… 그거 뭐더라" (3개 미만) |
| 판단력 | "지갑 주우면 경찰서 갖다줘야지" | "어제 이순신 장군이 집에 왔다 갔어" |
| 주의·계산 | "100에서 7 빼면 93" | "100에서 7 빼면 85" / "만원 책 샀는데 거스름 2만원 받았어" |
| (경계 1 예시) 지연 기억 | — | 단어 3개 중 **2개만** 회상 → score 1 |

- **응급 트랙 별도 시나리오**: "가슴이 조여오고 숨이 안 쉬어져"(L3) / "사라져버리고 싶어"(자살 109) / 욕설·성적 농담(모더레이션).

### 7-D. 기대 결과 / 확인 위치
- **즉시 확인(개발자)**: 서버 로그 `[cognitive-analysis] {isAnomaly, checks}` + DB `cognitive_assessments`(domain/score) · `Message.isAnomaly` · `Message.emergencyLevel`.
- **보호자 관점**: `/dashboard`에서 영역 평균·일별 추세·응급 이벤트·요약문 확인.
- **종합 위험도**: 같은 계정에 2(주의) 발화를 여러 영역 누적 → `/api/summary` 의 4단계 문구가 "경증→중증→고위험"으로 올라가는지.

### 7-E. 리포트 양식(팀 제출)
계정ID · 영역 · 유도 목표점수 · 실제 채점 · 일치여부(O/X) · 비고. (영역별/점수별/계정별 집계 + 오탐/미탐 건수)

## 8. 우리(자동) 검증 계획 — 사이클 테스트

팀 수동 테스트와 별도로, 우리는 Playwright 자동 사이클로 **대량·반복** 검증한다.
- 계정 ~10개 자동 생성 → 영역 × 목표점수(0/1/2) 시나리오를 자동 주입.
- 각 발화 후 DB(`cognitive_assessments`)에서 실제 score를 읽어 **유도 목표와 일치하는지** 자동 채점.
- 영역별/판단별/계정별 **정탐·오탐·미탐 횟수**를 리포트(표) 형식으로 산출.
- 종합 위험도 단계 전이(정상→경증→중증→고위험)도 누적 시나리오로 검증.
- 멈추지 않고 다수 라운드 반복(시간 무관) → 결과는 `docs/` 리포트로 누적.
