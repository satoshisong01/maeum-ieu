## §2.5 발견 문제 → 원인분석 → 재발방지 (검증의 핵심)

| # | 발견 문제 | 원인 분석 | 재발방지 조치 | 재검증 |
|---|-----------|-----------|----------------|--------|
| P1 | **장소 경증 0%** (1로 안 잡힘) | 테스트 유도 문장이 설계 기준("틀린 장소 + 회상 hedge → 2를 1로 강등")과 불일치. 분석기는 정상 작동 | 유도 문장을 "여기가 부산인가… 예전에 살던 생각이 나서 헷갈리네"처럼 **틀린 장소 + 명시적 회상 표현**으로 교정 | 0% → **100%** |
| P2 | **시간 경증 0%** (1 대신 2로 감지) | 🔴 **분석기 프롬프트 결함**: "회상 hedge 동반 시 2→1 강등" 규칙이 *장소 지남력에만* 있고 *시간 지남력엔 누락*. 두 항목이 같은 '지남력'인데 비대칭 | `cognitive-analyzer.ts` 시간 섹션에 **동일 강등 규칙 추가** | 0% → **100%** |
| P3 | P2 fix 부작용: **시간 중증 100%→50%** | 추가한 강등 트리거에 꼬리표 의문("~이지?/~인가?")이 포함돼, *확신에 찬 오답*("오늘 2003년이지?")까지 불확실로 오판 | 트리거를 **명시적 회상·자기불확실 단어**(옛날/예전/생각이 나서/헷갈리네)로 좁히고, **단순 꼬리표 의문은 강등 금지** 명문화 | 50% → **100%** |
| P4 | **계산 경증 0%** (설계 미정의) | MMSE-K 100-7은 다단계인데 "2회 이상 오류→2"만 있고 **1회 오류 등급(경계) 미정의** | 계산 섹션에 **"1회 오류·머뭇·자가수정 → score 1"** 추가 (MMSE-K 채점 세분화) | 0% → **100%** |
| P5 | **판단력 정상 38%** (0 기록 누락) | 정상 판단 답변을 score 0으로 **기록하지 않는 경우 잦음**(오분류는 아님 — 이상으로 잡힌 적 0). 재질문 방지·통계 누락 위험 | 판단 섹션에 **정상(0) 반드시 기록 + 예시** 명시 | 38% → **100%** |

### 설계 명확화 (재발방지 — 향후 오해 차단)
- **경증(1, 경계)이 "설계된" 항목**: 시간·장소(틀림+회상hedge), 지연기억(3단어 중 2개·5단어 중 2~3개), 언어(동물 5~8개·속담 직역), 계산(1회 오류). → 이 항목들만 경증 칸을 채점·검증.
- **경증이 설계 안 된 항목(정상/주의 이진)**: 판단력·즉시기억. 이 항목의 경증은 **개별 점수가 아니라 종합 위험도(overallAvg) 평균에서** 자연 발생.
- **부작용 회귀 방지**: 위 매트릭스(`scripts/matrix-verify.ts`)를 분석기 프롬프트 수정 시마다 실행 → 한 칸 고치다 다른 칸 깨지는지(P3 유형) 즉시 검출. 안전망 회귀(`safety-regression.ts` 26케이스)도 함께 통과 확인(이번 수정 후 26/26 유지).

## §2.6 종합 위험도 4단계 — "어떻게 답하면 어떤 등급인지"

개별 발화 점수(0/1/2)가 기간 누적되어 **가중 평균(overallAvg)** 으로 4단계 등급이 정해진다. (`lib/health/severity.ts`, summary API)

### 판정 기준
| 등급 | overallAvg | 보호자 안내 | 어떤 답변이 모이면 이 등급인가 |
|------|-----------|-------------|--------------------------------|
| 🟢 **정상** | `< 0.3` | "정상 범위" | 인지 질문에 대부분 정확히 답(날짜 맞춤·단어 3개 회상·100-7=93·지갑→경찰서) |
| 🟡 **경증** | `0.3 ~ 0.8` | "경미한 변화, 모니터링 권장" | 경계 답이 드문드문(단어 2/3·동물 6개·회상hedge 동반 시간/장소·100-7 1회오류) + 정상 다수 |
| 🟠 **중증** | `0.8 ~ 1.5` | "인지 저하 가능성, 전문의 상담" | 여러 영역에서 주의(틀린 날짜/장소·회상 실패·계산 오류) 답이 섞임 |
| 🔴 **고위험** | `≥ 1.5` | "심각한 인지 저하 의심, 즉시 상담" | 사망인물·시대착오·장소혼동·계산불가 등 **주의(2) 답변이 다발** |

### 검증 결과
- **판정 로직(경계값·가중평균·답변패턴 35케이스): `scripts/tier-verify.ts` → 35/35 (100%)**
  - 경계 0.3/0.8/1.5 전후 정확, "평가전(-1)" 포함.
- **실제 앱 전구간(Playwright → /api/summary): `scripts/e2e-tier.mjs` → 3/3 (100%)**

| 프로필 | 보낸 답변 성격 | overallAvg | 판정 등급 |
|--------|----------------|-----------|-----------|
| 정상군 | 전부 정상 일상 답변 | 0.0 | 🟢 정상 |
| 혼합 | 이상 2 + 정상 4 | 1.0 | 🟠 중증 |
| 이상다발 | 이상 6(사망인물·뉴욕·계산불가 등) | 1.71 | 🔴 고위험 |

→ **답변이 나빠질수록 등급이 정확히 상승**(0.0 → 1.0 → 1.71). 단조성·경계 모두 설계대로.

### 재발방지 (코드 개선)
- 등급 판정을 `lib/health/severity.ts` 순수 함수(`computeOverallAvg`, `classifySeverity`)로 **분리** → summary route가 import. 임계값 변경 시 `tier-verify.ts`가 즉시 회귀 검출. summary 응답에 `severityTier` 필드 추가(대시보드 직접 사용 가능).
