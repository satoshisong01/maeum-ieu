# AI 판단 정확도 검증 — 종합 (정상 / 경증 / 중증 / 고위험)

작성: 2026-06-02 · 모델: **gemini-3.5-flash** · 방식: 판단 엔진(`analyzeCognitive`) 직접 호출, 각 케이스의 **질문 → 대답 → 판단** 기록

## 한 줄 결론
정상 답변은 정상으로, 경계는 경증으로, 이상은 중증으로, 누적 위험은 고위험으로 — **레벨별 판단이 설계대로 정확**(종합 64/65 = 98.5%).

## 레벨별 결과
| 레벨 | 무엇을 검증 | 케이스 | 정확도 | 문서 |
|------|-------------|--------|--------|------|
| 🟢 **정상** | 정상 답변을 정상(score 0)으로 판단하는가 (오탐 0) | 20 | **20/20 (100%)** | [판단검증_정상.md](판단검증_정상.md) |
| 🟡 **경증** | 경계 답변을 경증(score 1)으로 판단하는가 | 14 | **13/14 (92.9%)** | [판단검증_경증.md](판단검증_경증.md) |
| 🟠 **중증** | 이상 답변을 중증(score 2)으로 판단하는가 | 20 | **20/20 (100%)** | [판단검증_중증.md](판단검증_중증.md) |
| 🔴 **종합등급(고위험 포함)** | 누적 답변 → overallAvg → 4단계 등급 | 11 프로파일 | **11/11 (100%)** | [판단검증_고위험.md](판단검증_고위험.md) |

> **고위험은 왜 개별 케이스가 아니라 프로파일인가?** 정상(0)·경증(1)·중증(2)은 *발화 단위 점수*라 질문 1개로 검증되지만, **고위험은 발화 단위 점수가 아니라 여러 발화의 누적 평균이 1.5 이상일 때 나오는 종합등급**입니다. 따라서 "고위험 답변 1개"는 존재할 수 없고, 누적 시나리오(프로파일)로만 검증합니다. 본 검증은 **고위험 집중 시나리오 7종**(사망인물 다발·시대착오 다발·장소혼동+계산붕괴·비현실 경험·지남력붕괴+회상실패·혼합 중증)을 포함해 11개 프로파일을 검증했습니다.

## 발화 단위 판단 (정상/경증/중증)
- **정상 20/20**: 시간·장소·기억·언어·판단·계산 정상 답변 + 일상 발화 전부 score 0, 오탐 0건.
- **경증 13/14**: 시간/장소 경계(틀림+회상hedge), 지연기억 2/3 회상, 동물 6~7개, 계산 1회 자가수정 등 정확히 score 1.
  - 미스 1건: "소 개 돼지 염소 닭"(정확히 5개) → `language:0`. **5개는 정상↔경증 경계**(가이드: 5~8개=경증, 5개 미만=중증)라 분석기가 정상으로 판단 — 경계 케이스의 방어 가능한 판정.
- **중증 20/20**: 확신 연도/장소 오류, 사망인물 현재접촉, 비현실(외계인/용), 회상 실패, 불가능 거래 등 전부 score 2.

## 종합등급 4단계 (누적 평균 → 등급)
임계: `<0.3 정상 · <0.8 경증 · <1.5 중증 · ≥1.5 고위험` (`lib/health/severity.ts`)

**스펙트럼 (단조 상승 확인)**
| 프로파일 | 답변 성격 | overallAvg | 판정 등급 | 기대 |
|----------|-----------|-----------|-----------|------|
| 정상군 | 전부 정상 답변 | 0.000 | 🟢 정상 | ✅ |
| 경증군 | 정상 다수 + 경계 일부 | 0.333 | 🟡 경증 | ✅ |
| 중증군 | 단일도메인 이상 3 + 정상 2 | 1.200 | 🟠 중증 | ✅ |
| 고위험군 | 다영역 이상 다발 | 2.000 | 🔴 고위험 | ✅ |
→ 답변이 나빠질수록 등급이 **단조 상승**(0.0 → 0.33 → 1.2 → 2.0).

**고위험 집중 시나리오 (7종 모두 고위험으로 판정)**
| 시나리오 | overallAvg | 판정 |
|----------|-----------|------|
| 사망인물 다발(박정희·이순신·돌아가신 영감·김구) | 2.000 | 🔴 고위험 ✅ |
| 시대착오 다발(1988올림픽·새마을·유신·한겨울) | 2.000 | 🔴 고위험 ✅ |
| 장소혼동+계산붕괴(뉴욕·해운대·거스름불가) | 2.000 | 🔴 고위험 ✅ |
| 비현실 경험(외계인·용·공룡) | 2.000 | 🔴 고위험 ✅ |
| 지남력붕괴+회상실패 | 2.000 | 🔴 고위험 ✅ |
| 혼합 중증 다발 | 2.000 | 🔴 고위험 ✅ |
| (스펙트럼) 고위험군 | 2.000 | 🔴 고위험 ✅ |

**경계 케이스**: "중증 상한(이상 3 + 정상 3)" → avg 1.200 → 🟠 중증 (1.5 미만, 고위험 아님) ✅ — 1.5 임계 경계가 정확히 작동.
